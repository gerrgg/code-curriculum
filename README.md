# Code Curriculum

Learn web development on your own computer. Start with a Windows 11 PC, create a page in a local editor, then set up Ubuntu for command-line work.

## Windows foundations

1. [Make a page you can find again](lessons/windows/first-page.md)
2. [Open a project in Ubuntu](lessons/windows/wsl-workspace.md)

Planned projects include building a two-page site, recording changes with Git, publishing the site, and responding to a maintenance request.

## Contribute

Lessons are Markdown files. Use the links at the end of a lesson to suggest an edit, report a broken link, describe a confusing step, or review its history. For an edit, propose a change in a pull request and say how you checked it. Contributions use the [curriculum license](LICENSE.md).
